# Community profiles: the data

This branch holds the community profiles people shared from LLMSelfbot. It's written by the **Community** workflows
on `main` (their code is in `community/` there), not by hand, and shares no history with the app's code.

| | |
|---|---|
| `profiles/<slug>/` | One live profile: its details, text, settings, face and thumbnails |
| `community.json` | Moderators, limits, tags, banned words and authors. Edit this one by hand to change them |
| `retired.json` | Short names taken out of the catalog, and by whom |
| `stats/history.json` | Downloads so far, one point a day |
